  Complete Flow                                                                                                                                
  USER clicks "Talk to Sethu" on Dashboard                                                                                                            │                                                                                                                               
          ▼ AudioContext created (male voice)
  ┌─────────────────────────────┐
  │  PHASE 1 — ONBOARDING       │
  │  Agent: steering_manager    │

  │  Sethu speaks in English:   │
  │  Step 1 → detects LANGUAGE  │  [LANG:te/hi/ta/kn/mr]
  │  Step 2 → detects JOB       │  [JOB:driver/plumber/...]
  │  Step 3 → detects COUNTRY   │  [COUNTRY:dubai/japan/...]
  │                             │
  │  "Handing you to expert..." │
  └──────────────┬──────────────┘
                 │ onComplete(lang, job, country)
                 ▼
       POST /api/session → Neon DB
       Returns sessionId → redirect
                 │
                 ▼
  ┌─────────────────────────────┐
  │  /session/[sessionId]       │
  │  Shows: Language | Job |    │
  │  Destination | Target lang  │
  │                             │
  │  "Start Learning" button    │
  └──────────────┬──────────────┘
                 │ Click → AudioContext created (female voice)
                 ▼
       POST /api/agents → picks NativeLingo
       system prompt by nativeLanguage
                 │
                 ▼
  ┌─────────────────────────────┐
  │  PHASE 2 — LEARNING         │
  │  Agent: nativelingo_[lang]  │
  │  Voice: Female (Aoede)      │
  │                             │
  │  Per word teaching loop:    │
  │  a) Native language meaning │
  │  b) Foreign word            │
  │  c) Phonetic guide          │
  │  d) "Say it" — user repeats │
  │  e) Feedback in native lang │
  │  f) Review every 3-4 words  │
  └─────────────────────────────┘
